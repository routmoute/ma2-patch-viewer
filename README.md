# MA2 Patch Viewer

MA2 Patch Viewer turns a **grandMA2** XML patch export into a clear, printable patch sheet. It shows layers, fixtures, DMX universes, addresses, and channel counts to help prepare and document a show.

## Access

The application is available online:

https://routmoute.github.io/ma2-patch-viewer/

## Usage

1. Export the patch from grandMA2 in XML format.
2. Drag the `.xml` file into the application, or select it from your computer.
3. Review the generated patch sheet, then print it or save it as a PDF.

You can also add an optional logo to the patch sheet.
